

.. _data-management:

=================
Data Management
=================

PyMoDAQ-BeamShaping uses **HDF5** files to store beam data, ensuring **portability**, **self-description**, and **compatibility** with other PyMoDAQ plugins.
This section describes the **file formats**, their **internal structure**, and how to **read/write** them programmatically.

---

.. _file-formats:

File Formats
------------

Two file extensions are used:

- **.h5field**: Single **2D complex field** (amplitude + phase) from the **Field Loader** (Input or Target).
- **.h5beam**: Complete **beam shaping session** (Input + Target + SLM phases + Algorithm results).

Both formats are **HDF5-based** and follow the **PyMoDAQ data model** (compatible with ``pymodaq_data >= 5.1.0``).

---

.. _h5field-format:

.h5field Format
~~~~~~~~~~~~~~~~

**Purpose**: Store a **single 2D field** (e.g., input beam, target beam).
**Generated by**: :ref:`Field Loader <field-loaders>` (Input or Target).

.. _h5field-structure:

**HDF5 Structure**
""""""""""""""""""

The ``.h5field`` file has the following hierarchy:

.. code-block:: text

    /
    ├── [Global Attributes]                     # Metadata (date, version, etc.)
    │
    └── RawData/ (GROUP)
        ├── Field/ (GROUP)                     # Main field container
        │   ├── @settings: <binary>             # Loader configuration (XML)
        │   │
        │   ├── Axis00 (CARRAY)                # Horizontal axis (X) in meters
        │   ├── Axis01 (CARRAY)                # Vertical axis (Y) in meters
        │   ├── Data00 (CARRAY)                # **Amplitude** (2D array, float64)
        │   └── Data01 (CARRAY)                # **Phase** (2D array, float64, radians)
        │
        └── Logger (VLARRAY)                   # Log messages (optional)

.. list-table:: **Key Attributes in .h5field**
   :header-rows: 1
   :widths: 30 20 50
   :class: longtable

   * - **Location**
     - **Attribute**
     - **Description**
   * - ``/``
     - ``date``, ``time``
     - File creation timestamp (format: ``YYYY-MM-DD``, ``HH:MM:SS.microseconds``).
   * - ``/``
     - ``pymodaq_version``, ``pymodaq_data_version``
     - PyMoDAQ and pymodaq_data versions used to create the file.
   * - ``/RawData/Field/Axis00``
     - ``scaling``
     - **Pixel size in meters** (e.g., ``6.494e-06`` for 6.494 µm/pixel).
   * - ``/RawData/Field/Axis00``
     - ``units``
     - Physical unit for the axis (``"m"`` for meters).
   * - ``/RawData/Field/Data00``
     - ``label``
     - **Data type** (``"Amplitude"`` or ``"Phase"``).
   * - ``/RawData/Field/Data00``
     - ``shape``
     - Dimensions of the 2D array (e.g., ``(1024, 1024)``).
   * - ``/RawData/Field``
     - ``settings``
     - **Serialized XML configuration** of the Field Loader (includes loader type, parameters, masking, etc.).

.. note::
   - The **amplitude** and **phase** are stored as **separate datasets** (``Data00`` and ``Data01``).
   - The **physical coordinates** (in meters) are defined by ``Axis00`` (X) and ``Axis01`` (Y).
   - The ``scaling`` attribute of each axis gives the **pixel pitch** in meters.

---

.. _h5beam-format:

.h5beam Format
~~~~~~~~~~~~~~

**Purpose**: Store a **complete beam shaping session**, including:
- Input and Target fields.
- SLM phases (algorithm, quadratic, linear, Zernike).
- Algorithm results (output field, modulator field, metrics).
- Global configuration (wavelength, setup type, etc.).

**Generated by**: :ref:`Beam Shaping Extension <beam-shaping-extension>`.

.. _h5beam-structure:

**HDF5 Structure**
""""""""""""""""""

The ``.h5beam`` file has the following hierarchy:

.. code-block:: text

    /
    ├── [Global Attributes]                     # Metadata (date, version, etc.)
    │
    └── RawData/ (GROUP)
        ├── @settings: <binary>                # **Global configuration** (XML)
        │                                      # Includes: wavelength, setup_type (2f/4f/no_lens),
        │                                      # SLM settings, default loaders, etc.
        │
        ├── Algorithm/ (GROUP)                 # Algorithm configuration and results
        │   ├── @settings: <binary>            # Algorithm settings (XML)
        │   │
        │   ├── Data0D/ (GROUP)                # **Scalar metrics**
        │   │   └── CH00/ (GROUP)
        │   │       ├── Data00 (CARRAY)        # **NRMSE** (Normalized Root Mean Square Error)
        │   │       └── Data01 (CARRAY)        # **Efficiency** (beam shaping efficiency)
        │   │
        │   └── Data2D/ (GROUP)                # **2D results**
        │       ├── CH00/ (GROUP)              # **Output Field Amplitude**
        │       │   ├── Axis00, Axis01          # Coordinates (m)
        │       │   └── Data00 (CARRAY)        # Amplitude (2D array)
        │       │
        │       ├── CH01/ (GROUP)              # **Output Field Phase**
        │       │   └── Data00 (CARRAY)        # Phase (2D array)
        │       │
        │       ├── CH02/ (GROUP)              # **Modulator Amplitude** (sent to SLM)
        │       │   └── Data00 (CARRAY)
        │       │
        │       └── CH03/ (GROUP)              # **Modulator Phase** (sent to SLM)
        │           └── Data00 (CARRAY)
        │
        ├── Input/ (GROUP)                     # **Input Field** (source beam)
        │   ├── @settings: <binary>            # Input Field Loader configuration
        │   ├── Axis00, Axis01                 # Coordinates (m)
        │   ├── Data00 (CARRAY)                # Amplitude
        │   └── Data01 (CARRAY)                # Phase
        │
        ├── Target/ (GROUP)                    # **Target Field** (desired output)
        │   ├── @settings: <binary>            # Target Field Loader configuration
        │   ├── Axis00, Axis01
        │   ├── Data00 (Amplitude)
        │   └── Data01 (Phase)
        │
        ├── SLM/ (GROUP)                       # **SLM Phases**
        │   └── Data2D/ (GROUP)                # Phases by channel
        │       ├── CH00/ (GROUP)              # **Algorithm Phase** (to be applied to SLM)
        │       │   ├── Axis00, Axis01          # SLM coordinates (m)
        │       │   └── Data00 (CARRAY)        # Phase (2D array, shape: (540, 960))
        │       │
        │       ├── CH01/ (GROUP)              # **Quadratic Phase** (curvature correction)
        │       │   └── Data00 (CARRAY)
        │       │
        │       ├── CH02/ (GROUP)              # **Linear Phase** (tilt correction)
        │       │   └── Data00 (CARRAY)
        │       │
        │       └── CH03/ (GROUP)              # **Zernike Phase** (aberration correction)
        │           └── Data00 (CARRAY)
        │
        └── Logger (VLARRAY)                   # Log messages (optional)

.. list-table:: **Key Components in .h5beam**
   :header-rows: 1
   :widths: 25 25 50
   :class: longtable

   * - **Group**
     - **Purpose**
     - **Key Data**
   * - ``/RawData/Input``
     - Source beam field
     - Amplitude + Phase (2D arrays)
   * - ``/RawData/Target``
     - Desired output field
     - Amplitude + Phase (2D arrays)
   * - ``/RawData/Algorithm/Data0D/CH00``
     - **Performance metrics**
     - NRMSE (``Data00``), Efficiency (``Data01``)
   * - ``/RawData/Algorithm/Data2D/CH00``
     - **Output field amplitude**
     - 2D array (same size as Input/Target)
   * - ``/RawData/Algorithm/Data2D/CH01``
     - **Output field phase**
     - 2D array (radians)
   * - ``/RawData/Algorithm/Data2D/CH02``
     - **Modulator amplitude**
     - 2D array (sent to SLM)
   * - ``/RawData/Algorithm/Data2D/CH03``
     - **Modulator phase**
     - 2D array (radians)
   * - ``/RawData/SLM/Data2D/CH00``
     - **Algorithm phase for SLM**
     - 2D array (shape matches SLM resolution, e.g., 540x960)
   * - ``/RawData/SLM/Data2D/CH01``
     - **Quadratic phase correction**
     - 2D array
   * - ``/RawData/SLM/Data2D/CH02``
     - **Linear phase correction**
     - 2D array
   * - ``/RawData/SLM/Data2D/CH03``
     - **Zernike phase correction**
     - 2D array

.. note::
   - The **SLM phases** (``/RawData/SLM/Data2D/``) are **downsampled** to match the SLM resolution (e.g., 960x540 for PLUTO, 1024x768 for LC2012).
   - The **Algorithm/Data2D** results are at the **same resolution as the Input/Target fields** (e.g., 1024x1024).
   - The ``@settings`` attributes contain **serialized XML configurations** (can be deserialized with ``pymodaq_utils``).



Programmatic Access with `pymodaq_data`
---------------------------------------
You can **read `.h5beam` and `.h5field` files programmatically** using `pymodaq_data` (compatible with HDF5):

.. code-block:: python

   from pymodaq_data.h5modules.data_saving import DataLoader
   from pymodaq_data import DataToExport, DataWithAxes

   # Load data from a .h5beam file
   with DataLoader("my_file.h5beam") as loader:
       # Access SLM phases
       phase_data = loader.load_data("/RawData/SLM/Data2D/CH00")  # return a DataWithAxes object

       # Access metadata
       print(phase_data.extra_attributes)



.. _h5-attributes-reference:

HDF5 Attributes Reference
--------------------------

.. list-table:: **Global Attributes (Root Level)**
   :header-rows: 1
   :widths: 25 20 55
   :class: longtable

   * - **Attribute**
     - **Type**
     - **Description**
   * - ``CLASS``
     - string
     - HDF5 class (always ``"GROUP"`` at root).
   * - ``TITLE``
     - string
     - Human-readable title (``"PyMoDAQ file"``).
   * - ``date``
     - string
     - Creation date (format: ``YYYY-MM-DD``).
   * - ``time``
     - string
     - Creation time (format: ``HH:MM:SS.microseconds``).
   * - ``file``
     - string
     - Original filename.
   * - ``pymodaq_version``
     - string
     - PyMoDAQ version (e.g., ``"5.2.0"``).
   * - ``pymodaq_data_version``
     - string
     - pymodaq_data version (e.g., ``"5.1.10"``).

.. list-table:: **Axis Attributes (Axis00/Axis01)**
   :header-rows: 1
   :widths: 25 20 55
   :class: longtable

   * - **Attribute**
     - **Type**
     - **Description**
   * - ``scaling``
     - float64
     - **Pixel size in meters** (e.g., ``6.494e-06`` for 6.494 µm).
   * - ``offset``
     - float64
     - Physical offset (usually ``0.0``).
   * - ``units``
     - string
     - Physical unit (``"m"`` for meters).
   * - ``label``
     - string
     - Axis name (``"Hor Axis"`` or ``"Ver Axis"``).
   * - ``index``
     - int
     - Axis index (``1`` for X, ``0`` for Y).

.. list-table:: **Data Attributes (Data00/Data01)**
   :header-rows: 1
   :widths: 25 20 55
   :class: longtable

   * - **Attribute**
     - **Type**
     - **Description**
   * - ``label``
     - string
     - Data type (``"Amplitude"`` or ``"Phase"``).
   * - ``shape``
     - tuple
     - Array dimensions (e.g., ``(1024, 1024)``).
   * - ``dtype``
     - string
     - Data type (``"float64"``).
   * - ``source``
     - string
     - Data source (``"calculated"`` or ``"raw"``).
   * - ``timestamp``
     - float64
     - Unix timestamp of data acquisition.
