PyMoDAQ-BeamShaping Documentation
==================================

PyMoDAQ-BeamShaping is a **PyMoDAQ extension** for **spatial beam shaping** using Spatial Light Modulators (SLMs).
It enables dynamic control of **phase and/or amplitude** of optical fields to generate custom beam profiles.

   :alt: BeamShaping User Interface
   :width: 100%

   BeamShaping user interface.
   All modules are controlled from this interface.
